Support

Need help or found a bug? Write to sunbeam.studio@outlook.com. Please mention your device and system version (for example, “MacBook Pro, macOS 26”).

How do I add my music?

On Mac, open Folders and choose Add Folder… — any folder on your Mac, an external drive or iCloud Drive works. On iPad and iPhone, choose Add Folder… and pick a folder in the Files app: iCloud Drive, an external drive, or the Loco folder, which you can fill from a Mac through the Finder.

Why can’t Loco see the songs in the Music app?

Music synced to the Music app on iPhone and iPad is kept in the system media library, which apps can’t access as files. Loco plays music files from folders.

Some songs in iCloud Drive show “Not downloaded”

Loco doesn’t download files on its own while scanning. Tap the download button next to a song or a folder, then scan the folder again.

How do I get gapless playback and the equalizer?

In Settings, turn on the audio engine. Switching engines stops playback.

How do lyrics work?

Loco shows lyrics from an .lrc file with the same name as the song, in the same folder, or from lyrics embedded in the song’s tags. Synced lyrics follow the song. You can add or edit lyrics in Edit Tags.

Which files can Loco edit?

Tags, artwork and lyrics can be edited in MP3, FLAC and M4A files. Loco checks after every write that the audio stayed exactly the same and restores the file if it didn’t.

Can I use my Windows playlists?

Yes. Import M3U, M3U8, PLS, WPL (Windows Media Player) or ZPL (Zune) files in Playlists. The songs must be in a folder you’ve added to Loco; Loco matches them even when the playlist uses Windows paths.
